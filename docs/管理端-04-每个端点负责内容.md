# 管理端 · 每个端点负责内容

按管理后台页面说明：每个接口给哪一块 UI / 流程用、读哪些字段。  
路径均相对于 `{BASE}`（`{HOST}/api`），登录接口除外。

---

## 登录

| 端点 | 负责内容 |
|------|----------|
| `POST /api/passport/auth/login`（`require_admin: true`） | 管理后台登录；拿到 `token` / `auth_data` 写入本地后进仪表盘 |
| `POST /api/passport/auth/logout` | 退出并清本地 Token；多会话时只清当前会话 |

未带管理员权限或 Token 失效时，前端应跳回登录页。

---

## 仪表盘

| 端点 | 负责内容 |
|------|----------|
| `GET /stat/getStats` | 顶部/卡片：今日/昨日/本月收入、佣金、用户数、在线、待处理工单、在线节点 |
| `GET /stat/getOrder` | 收入趋势图：按日 `paid_total` / `paid_count` |
| `GET /stat/getTrafficRank` | 流量排行榜（用户或节点，视 `type`） |
| `GET /system/getSystemStatus` | 系统健康摘要（调度是否在跑等） |

金额字段按分展示时需 `/100`。仪表盘通常不写配置，只读统计。

## 系统设置 · 配置

| 端点 | 负责内容 |
|------|----------|
| `GET /config/fetch?key=site` | 站点名、Logo、URL、货币符号等表单回填 |
| `POST/PUT /config/site` | 保存站点 Tab |
| `GET /config/fetch?key=subscribe` | 订阅域名、路径、路径混淆等 |
| `POST/PUT /config/subscribe` | 保存订阅 Tab |
| `GET /config/fetch?key=invite` | 邀请比例、提现开关与方式、最低额度 |
| `POST/PUT /config/invite` | 保存邀请佣金 Tab |
| `GET /config/fetch?key=server` | 节点相关全局配置 |
| `POST/PUT /config/server` | 保存节点配置 Tab |
| `GET /config/fetch?key=mail` | SMTP / 发信人等 |
| `POST/PUT /config/mail` | 保存邮件 Tab |
| `POST /config/testSendMail` | 「发送测试邮件」按钮 |
| `GET /config/fetch?key=subscribe_template` | 订阅客户端提示模板 |
| `POST/PUT /config/subscribe-template` | 保存订阅模板 Tab |
| `GET /config/fetch?key=safe` | 注册限制、验证码、邮箱白名单等 |
| `POST/PUT /config/safe` | 保存安全 Tab |
| `DELETE /config/{module}?name=` | 删除单项后刷新该模块表单 |

未知字段会 `UNKNOWN_FIELDS`，前端应提示勿提交未定义键。

## 元数据（全局）

| 端点 | 负责内容 |
|------|----------|
| `GET /type/fetch?key=` | 任意模块下拉：订单类型、优惠券类型、协议、礼品卡、插件等 |

## 请求层公共行为（管理前端）

典型约定：

- 所有 `{BASE}` 请求附加 `Authorization: Bearer <token>`
- 写入多为 JSON；表格列表用 `pageSize` / `current` / `filter` / `sort`
- 收到未登录 / 非管理员错误时清 Token 并跳转登录
- 注意部分接口**无** `status` 包络：用 `data` / `success` / `total` 判断，勿一律读 `response.status === 'success'`

对接后端时：管理登录必须返回可用 Token 且 `is_admin` 为真；业务错误靠 HTTP 状态或 `message` / `error` 展示即可。

字段级白名单与筛选细则见 `docs/admin/` 各模块文档。
