# 期望端点列表

依据本主题 `src/api/endpoints.js` 与各页面实际调用整理。

## 约定

| 项 | 说明 |
|----|------|
| 前缀 `{BASE}` | `VUE_APP_API_BASE_URL`，必须带 **`/api/v1`**。本地示例：`http://127.0.0.1:3000/api/v1` |
| 路径 | 下表路径均相对于 `{BASE}`，不含前缀 |
| POST | `Content-Type: application/x-www-form-urlencoded` |
| 登录后 | 请求头 `Authorization: Bearer <jwt>` |
| 金额 | 单位为 **分**（前端 `/ 100` 显示） |
| 时间 | Unix **秒**（前端 `* 1000` 转 Date） |

错误示例：`http://127.0.0.1:3000/api/user/getStat`（缺 `/v1`）  
正确示例：`http://127.0.0.1:3000/api/v1/user/getStat`

## 非 Xboard 路径

| 方法 | 路径 | 说明 |
|------|------|------|

| GET | 第三方 IP 定位（ipwho.is 等） | `getIpLocationInfo()`，不经过 `{BASE}` |
