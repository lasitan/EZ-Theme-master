# 期望响应示例

成功时 HTTP 200，Xboard 常见包一层：

```json
{
  "status": "success",
  "message": "...",
  "data": {}
}
```

前端 axios 拦截器返回的是 **整个 body**（不是 axios `response`），页面读 `response.data`。  
未登录或 token 失效常见 `message` 为「未登录或登陆已过期」。

金额为分，时间为 Unix 秒。`null` 表示该周期/字段未启用，不要用 `0` 代替「不卖」。

## Guest

### GET `/guest/comm/config`

```json
{
  "status": "success",
  "data": {
    "is_email_verify": 1,
    "is_invite_force": 0,
    "email_whitelist_suffix": ["gmail.com", "qq.com"],
    "is_captcha": 0,
    "is_recaptcha": 0,
    "recaptcha_site_key": "",
    "app_description": "站点简介",
    "app_url": "https://example.com",
    "logo": null,
    "tos_url": null
  }
}
```

注册/登录页主要用 `is_email_verify`、`is_recaptcha`、`recaptcha_site_key`。

### GET `/guest/plan/fetch`

与登录后套餐列表结构相同，见下方 `/user/plan/fetch`。落地页读 `data` 数组。

## Passport

### POST `/passport/auth/login`

```json
{
  "status": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "auth_data": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "is_admin": 0
  }
}
```

前端以 `data.token` 为主，兼容 `auth_data`。缺 `token` 会视为登录失败。

### POST `/passport/auth/register`

```json
{
  "status": "success",
  "data": true
}
```

部分版本注册后直接返回与登录相同的 token 结构。

### POST `/passport/comm/sendEmailVerify`

```json
{
  "status": "success",
  "data": true
}
```

前端判断 `response.data === true`。

### POST `/passport/auth/forget`

```json
{
  "status": "success",
  "data": true
}
```

## User · 账号与订阅

### GET `/user/info`

```json
{
  "status": "success",
  "data": {
    "email": "user@example.com",
    "balance": 12800,
    "commission_balance": 3500,
    "telegram_id": null,
    "remind_expire": 1,
    "remind_traffic": 1,
    "uuid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "avatar_url": "https://..."
  }
}
```

余额、佣金单位为分。个人中心用 `remind_expire` / `remind_traffic`。

### GET `/user/getSubscribe`

```json
{
  "status": "success",
  "data": {
    "plan_id": 1,
    "token": "subscribe-token",
    "expired_at": 1735689600,
    "u": 1073741824,
    "d": 2147483648,
    "transfer_enable": 107374182400,
    "reset_day": 15,
    "subscribe_url": "https://example.com/s/xxxx",
    "device_limit": null,
    "alive_ip": 2,
    "allow_new_period": "0",
    "plan": {
      "id": 1,
      "name": "标准套餐",
      "reset_price": 500
    }
  }
}
```

| 字段 | 前端用途 |
|------|----------|
| `plan.name` / `plan.id` | 仪表盘套餐名、续费 |
| `expired_at` | `null` 视为永久；否则算剩余天数 |
| `transfer_enable` / `u` / `d` | 总流量与剩余流量（字节） |
| `reset_day` | 下次重置日 |
| `subscribe_url` | 导入订阅 |
| `device_limit` / `alive_ip` | 在线设备（若展示） |

### GET `/user/getStat`

```json
{
  "status": "success",
  "data": [2, 1, 8]
}
```

| 下标 | 含义 | 本主题 |
|------|------|--------|
| `[0]` | 待支付订单数 | 仪表盘「待处理订单」 |
| `[1]` | 待处理工单数 | 仪表盘「待处理工单」 |
| `[2]` | 邀请注册人数 | 未用 |

### GET `/user/comm/config`

```json
{
  "status": "success",
  "data": {
    "currency": "CNY",
    "currency_symbol": "¥",
    "withdraw_close": 0,
    "withdraw_methods": ["支付宝", "USDT"],
    "withdraw_limit": 10000,
    "commission_withdraw_limit": 100
  }
}
```

商店/仪表盘用 `currency`、`currency_symbol`；邀请页用提现相关字段。

### GET `/user/resetSecurity`

```json
{
  "status": "success",
  "data": "https://example.com/s/new-token"
}
```

`data` 为新的订阅 URL 字符串。

### GET `/user/getActiveSession`

```json
{
  "status": "success",
  "data": [
    {
      "id": "sess_1",
      "ip": "1.2.3.4",
      "is_current": 1,
      "login_at": 1700000000
    }
  ]
}
```

也可能是对象 map，前端会 `Object.values` 再按 `login_at` 排序，最多显示 10 条。

### POST `/user/changePassword` / `/user/update` / `/user/removeActiveSession`

```json
{
  "status": "success",
  "data": true
}
```

## User · 套餐 / 订单 / 支付

### GET `/user/plan/fetch`（列表）

```json
{
  "status": "success",
  "data": [
    {
      "id": 1,
      "group_id": 1,
      "name": "标准套餐",
      "content": "<p>套餐说明</p>",
      "transfer_enable": 100,
      "speed_limit": null,
      "device_limit": null,
      "show": 1,
      "sort": 1,
      "renew": 1,
      "month_price": 1000,
      "quarter_price": 2700,
      "half_year_price": 5000,
      "year_price": 9600,
      "two_year_price": null,
      "three_year_price": null,
      "onetime_price": null,
      "reset_price": 500,
      "capacity_limit": null
    }
  ]
}
```

`?id=1` 时 `data` 为 **单个对象**。`capacity_limit`：`null` 不限，`0` 售罄。价格为分，不卖的周期用 `null`。

### POST `/user/coupon/check`

固定金额（`type === 1`）：

```json
{
  "status": "success",
  "data": {
    "id": 1,
    "code": "SAVE20",
    "type": 1,
    "value": 200,
    "limit_use": null,
    "limit_plan_ids": null
  }
}
```

百分比（`type === 2`）：

```json
{
  "status": "success",
  "data": {
    "type": 2,
    "value": 20
  }
}
```

`type=1` 时 `value` 为分；`type=2` 时 `value` 为百分比。前端会对百分比再算 `originalPrice * value / 100`。

### POST `/user/order/save`

```json
{
  "status": "success",
  "message": "订单创建成功",
  "data": "202401010001"
}
```

`data` 是 `trade_no` 字符串，前端跳转 `/payment?trade_no=...`。

### GET `/user/order/fetch`

```json
{
  "status": "success",
  "data": [
    {
      "trade_no": "202401010001",
      "plan_id": 1,
      "period": "month_price",
      "total_amount": 1000,
      "status": 0,
      "created_at": 1700000000,
      "plan": { "id": 1, "name": "标准套餐" }
    }
  ]
}
```

订单 `status`：`0` 待支付，`1` 开通中，`2` 已取消，`3` 已完成。仅 `0` 可取消。

### GET `/user/order/detail`

```json
{
  "status": "success",
  "data": {
    "trade_no": "202401010001",
    "plan_id": 1,
    "period": "month_price",
    "total_amount": 800,
    "discount_amount": 200,
    "balance_amount": 0,
    "refund_amount": 0,
    "status": 0,
    "created_at": 1700000000,
    "plan": {
      "id": 1,
      "name": "标准套餐",
      "transfer_enable": 100
    }
  }
}
```

### GET `/user/order/check`

```json
{
  "status": "success",
  "data": 0
}
```

`data` 为状态码：`0` 待支付，`1` 已完成，`2` 已取消。支付页按此轮询。

### GET `/user/order/getPaymentMethod`

```json
{
  "status": "success",
  "data": [
    {
      "id": 1,
      "name": "支付宝",
      "icon": "https://example.com/alipay.png",
      "handling_fee_percent": 0,
      "handling_fee_fixed": 0
    }
  ]
}
```

### POST `/user/order/checkout`

扫码（`type === 0`）：

```json
{
  "status": "success",
  "type": 0,
  "data": "https://example.com/qr.png"
}
```

跳转链接（`type === 1`）：

```json
{
  "status": "success",
  "type": 1,
  "data": "https://pay.example.com/checkout/xxx"
}
```

`data` 为二维码图 URL 或支付跳转 URL。

## User · 工单

### GET `/user/ticket/fetch`（列表）

```json
{
  "status": "success",
  "data": [
    {
      "id": 12,
      "user_id": 1,
      "subject": "无法连接节点",
      "level": 1,
      "status": 0,
      "reply_status": 0,
      "created_at": 1700000000,
      "updated_at": 1700003600
    }
  ]
}
```

`status`：`0` 开启，`1` 已关闭。`level`：`0` 低 / `1` 中 / `2` 高。

### GET `/user/ticket/fetch?id=12`

```json
{
  "status": "success",
  "data": {
    "id": 12,
    "subject": "无法连接节点",
    "level": 1,
    "status": 0,
    "message": [
      {
        "id": 1,
        "ticket_id": 12,
        "message": "连不上节点",
        "is_me": true,
        "created_at": 1700000000
      },
      {
        "id": 2,
        "ticket_id": 12,
        "message": "请提供订阅截图",
        "is_me": false,
        "created_at": 1700001800
      }
    ]
  }
}
```

前端把 `is_me === false` 显示为管理员。`status === 1` 时隐藏回复框并停止轮询。

### POST `/user/ticket/save` / `reply` / `close`

```json
{
  "status": "success",
  "message": "工单已创建",
  "data": true
}
```

## User · 邀请

### GET `/user/invite/fetch`

```json
{
  "status": "success",
  "data": {
    "codes": [
      { "id": 1, "code": "ABCD12", "created_at": 1700000000 }
    ],
    "stat": [10, 50000, 12000, 20, 38000]
  }
}
```

| `stat` 下标 | 含义 | 前端 |
|-------------|------|------|
| `[0]` | 注册人数 | 原样 |
| `[1]` | 确认佣金（分） | `/100` |
| `[2]` | 待确认佣金（分） | `/100` |
| `[3]` | 佣金比例（%） | 原样 |
| `[4]` | 可提现佣金（分） | `/100` |

### GET `/user/invite/details`

```json
{
  "status": "success",
  "data": {
    "data": [
      {
        "id": 1,
        "created_at": 1700000000,
        "get_amount": 200,
        "order_amount": 1000
      }
    ],
    "total": 25
  }
}
```

前端把 `get_amount / 100` 当作佣金金额。

### POST `/user/transfer`

```json
{
  "status": "success",
  "data": true
}
```
