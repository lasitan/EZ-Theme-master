# 管理端 · 期望响应示例

成功时多数接口 HTTP 200，包络为：

```json
{
  "status": "success",
  "message": "操作成功",
  "data": {},
  "error": null
}
```

失败常见：

```json
{
  "status": "fail",
  "message": "未登录或登陆已过期",
  "data": null,
  "error": "UNAUTHORIZED"
}
```

配置模块非法字段时 `status` 可能为 `"error"`（非 `"fail"`）。

**无完整 `status` 包络的特例**（ProTable / 裸 `data`）：

| 形态 | 典型接口 |
|------|----------|
| `{ data: [...] }` | `GET /plan/fetch`、`GET /payment/fetch`、`GET /plugin/getPlugins` |
| `{ data, total, success, current, pageSize }` | `POST /order/fetch`、`POST /user/fetch`、`POST /coupon/fetch` 等 |
| `{ code, message, data }` | `GET /stat/getOrder` 等部分统计 |

金额多为分；时间为 Unix 秒（统计曲线常用 `YYYY-MM-DD`）。

## 认证

### POST `/api/passport/auth/login`（管理员）

```json
{
  "status": "success",
  "message": "操作成功",
  "data": {
    "token": "a1b2c3d4e5f6789012345678abcdef01",
    "auth_data": "a1b2c3d4e5f6789012345678abcdef01",
    "is_admin": 1,
    "multi_session": true
  },
  "error": null
}
```

`multi_session: true` 表示使用 `admin_auth_token` 多设备会话。

非管理员带 `require_admin`：

```json
{
  "status": "fail",
  "message": "权限不足：该账号不是管理员，无法登录管理后台（require_admin）。",
  "data": { "reason": "admin_required" },
  "error": "FORBIDDEN_NOT_ADMIN"
}
```

## 通用错误

| HTTP | `error` | 说明 |
|------|---------|------|
| 401 | `UNAUTHORIZED` / `INVALID_CREDENTIALS` | 未登录或密码错误 |
| 403 | `FORBIDDEN` / `FORBIDDEN_NOT_ADMIN` | 非管理员 |
| 400 | `INVALID_PARAMS` / `UNKNOWN_FIELDS` | 参数 / 配置字段错误 |
| 404 | `NOT_FOUND` | 资源不存在 |
| 500 | （实现消息） | 服务端异常 |
