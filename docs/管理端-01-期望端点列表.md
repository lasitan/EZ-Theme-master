# 管理端 · 期望端点列表

依据本项目 `server/http/router.js`、`server/http/adminDocumentedRoutes.js` 与管理后台页面调用整理。

## 约定

| 项 | 说明 |
|----|------|
| 前缀 `{BASE}` | `{HOST}/api`。本地示例：`http://127.0.0.1:3000/api` |
| `secure_path` | 仅用于管理端 **SPA 页面**路径 `/{secure_path}`，**不是** API 前缀 |
| 路径 | 下表路径均相对于 `{BASE}`，不含前缀（登录除外） |
| POST / PUT | 管理端多为 `Content-Type: application/json` |
| 登录后 | 请求头 `Authorization: Bearer <token>`，且账号 `is_admin=1` |
| 金额 | 订单/套餐等与库一致；管理端套餐价多为「分」或按字段说明 |
| 时间 | Unix **秒**（部分统计接口用日期字符串） |

本项目**不使用** `/api/v1` 版本前缀。  
错误示例：`http://127.0.0.1:3000/api/v1/admin/stat/getStats`  
正确示例：`http://127.0.0.1:3000/api/stat/getStats`

## 认证（Passport，不在 `{BASE}` 下）

| 方法 | 路径 | 用途 | 管理页 |
|------|------|------|--------|
| POST | `/api/passport/auth/login` | 管理员登录（Body 含 `require_admin: true`） | 登录 |
| POST | `/api/passport/auth/logout` | 退出当前会话 | 顶栏 / 个人 |

登录成功后拿到的 `token` 用于后续所有 `{BASE}` 请求。
