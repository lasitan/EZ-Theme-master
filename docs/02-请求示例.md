# 请求示例

`{BASE}` 以本地为例：`http://127.0.0.1:3000/api/v1`。  
登录后示例均带：

```http
Authorization: Bearer <jwt>
```

POST 均为 `application/x-www-form-urlencoded`（前端 axios 拦截器会把 JSON body 转成该格式）。

## Passport

### POST `/passport/auth/login`

```http
POST {BASE}/passport/auth/login
Content-Type: application/x-www-form-urlencoded

email=user@example.com&password=secret
```

### POST `/passport/auth/register`

```http
POST {BASE}/passport/auth/register
Content-Type: application/x-www-form-urlencoded

email=user@example.com&password=secret&email_code=123456&invite_code=ABCD&recaptcha_data=TOKEN
```

- `email_code`：站点开启邮箱验证时必填  
- `invite_code`：有邀请码时带上  
- `recaptcha_data`：开启验证码时带上  

### POST `/passport/auth/forget`

```http
POST {BASE}/passport/auth/forget
Content-Type: application/x-www-form-urlencoded

email=user@example.com&password=newSecret&email_code=123456
```

### POST `/passport/comm/sendEmailVerify`

注册：

```http
POST {BASE}/passport/comm/sendEmailVerify
Content-Type: application/x-www-form-urlencoded

email=user@example.com&isForgetPassword=0
```

找回密码：

```http
POST {BASE}/passport/comm/sendEmailVerify
Content-Type: application/x-www-form-urlencoded

email=user@example.com&isForgetPassword=1
```

可选：`recaptcha_data=TOKEN`

### GET `/passport/auth/token2Login`

```http
GET {BASE}/passport/auth/token2Login?verify=<token>&redirect=/dashboard
```

### POST `/passport/auth/loginWithMailLink`

```http
POST {BASE}/passport/auth/loginWithMailLink
Content-Type: application/x-www-form-urlencoded

email=user@example.com
```

### GET `/passport/auth/google/login`

浏览器跳转，不是 axios：

```
{BASE}/passport/auth/google/login?redirect=/dashboard
```

### POST `/user/order/save`

购买 / 续费：

```http
POST {BASE}/user/order/save
Authorization: Bearer <jwt>
Content-Type: application/x-www-form-urlencoded

plan_id=1&period=month_price&coupon_code=SAVE20
```

`period` 取值：`month_price` / `quarter_price` / `half_year_price` / `year_price` / `two_year_price` / `three_year_price` / `onetime_price` / `reset_price`  
`coupon_code` 可选。

重置流量（仪表盘）：

```http
POST {BASE}/user/order/save
Authorization: Bearer <jwt>
Content-Type: application/x-www-form-urlencoded

plan_id=1&period=reset_price
```
