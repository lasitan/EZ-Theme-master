# 管理端 · 请求示例

`{BASE}` 以本地为例：`http://127.0.0.1:3000/api`（将 `admin` 换成实际 `secure_path`）。  
登录后示例均带：

```http
Authorization: Bearer <token>
```

管理端写入类请求默认 `Content-Type: application/json`（插件上传为 `multipart/form-data`）。

表格分页接口常用 Body：

```json
{
  "pageSize": 20,
  "current": 1,
  "filter": [{ "id": "status", "value": "0", "operator": "eq" }],
  "sort": [{ "id": "created_at", "desc": true }]
}
```

## 认证（Passport）

### POST `/api/passport/auth/login`（管理员）

```http
POST {HOST}/api/passport/auth/login
Content-Type: application/json

{"email":"admin@example.com","password":"secret","require_admin":true}
```

`require_admin` 必须为 `true`，否则不会按管理会话签发。

### POST `/api/passport/auth/logout`

```http
POST {HOST}/api/passport/auth/logout
Authorization: Bearer <token>
```
